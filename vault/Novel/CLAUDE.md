## Where things go

| Folder | What lives there |
|---|---|
| `Chapters/` | The manuscript, one note per chapter: `Chapter 01 - Title`. Only Maxwell's prose. |
| `Characters/` | One note per character, flat. Importance is the `tier` property (Lead, Important, Minor), not a folder. |
| `World/` | One note per place, people, creature, faction, event, magic system, religion, language or thing. What it is goes in `type`. |
| `Notes/` | Plot plans, outlines, brainstorms, to-dos. |
| `Drafts/` | Older versions of chapters that were replaced. Kept, never deleted. |
| `Sources/` | The original files as they were brought in (docs, Claude chats). Read only. Obsidian hides this folder. |
