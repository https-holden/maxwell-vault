# A writer's vault

An Obsidian starter vault for morning pages (The Artist's Way) and a fantasy novel with a big
invented world. Made by Holden for Maxwell, from Holden's own vault.

- **New here?** [START-HERE.md](START-HERE.md)
- **Claude setting it up?** [SETUP.md](SETUP.md)
- **The vault itself:** [`vault/`](vault). Its `Readme.md` is the guide, its `CLAUDE.md` is
  how Claude works inside it.

## What's in it

- **Morning pages**: Cmd+Shift+M makes a dated page in `Journal/`, asks where you're writing
  from, and drops the cursor in. 750-word goal with a soft glow when you reach it.
- **Zen mode**: Cmd+Shift+P, full screen, typewriter scrolling and faded paragraphs.
- **The novel**: `Novel/` with chapters, characters and a world (places, peoples, creatures,
  factions, history as a timeline, magic, languages, things), each a sortable table, with an
  idea / draft / canon status so brainstorming never overwrites what's true.
- **Bringing things in**: drop files in `Inbox/`, Claude files them, keeps the originals and
  builds character and world notes from the chapters.
- **The Artist's Way**: a course hub and templates for weeks, exercises and artist dates.
- **The look**: the Analog theme (parchment, serif, violet accent, light and dark), spell
  check off.

Community plugins included: Templater, Dataview, ProZen, Typewriter Mode, Canvas Send to Back.
The rest are small plugins written for Holden's vault: Home Button, Word Goal Glow, Zen
Typewriter, Link Search, Auto Alias, Date Mentions, Quiet Properties, Resting View, Sticky
Bullets, Image Caption, HEIC Convert, Manual Modified.
